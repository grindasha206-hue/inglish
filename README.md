# Инглиш — мой сайт для изучения английского

Личный сайт для занятий английским: кабинет с прогрессом, плеер уроков, XP и серия дней.

## Из чего состоит

```
index.html    — кабинет (главная): кнопка «Продолжить», статистика, список уроков
player.html   — плеер: открывает урок и сам замечает, когда он пройден
course.js     — структура курса (ЕДИНСТВЕННЫЙ файл, который нужно править)
progress.js   — хранение прогресса (в localStorage браузера)
lessons/      — сами HTML-уроки
```

## Как открыть

Лучший способ — опубликовать на GitHub Pages (бесплатно) и открывать по ссылке
с любого устройства. Тогда работает всё, включая автоматическое определение
«урок пройден».

Локально без сервера (двойной клик по index.html) сайт тоже работает,
но некоторые браузеры не дают плееру заглянуть внутрь урока — тогда просто
нажимай кнопку «✓ Завершить урок» вручную.

## Как добавить новый урок

1. Положи HTML-файл урока в папку `lessons/`
2. Открой `course.js` и добавь строчку в нужный модуль:

```js
{ id:"unit-04", unit:4, title:"Название урока", description:"О чём урок", file:"lessons/имя-файла.html" }
```

`id` должен быть уникальным — по нему хранится прогресс.

## Прогресс

Прогресс (пройденные уроки, XP, серия дней) хранится в браузере.
Если переходишь на другой браузер или устройство — внизу кабинета есть кнопки
«Сохранить прогресс в файл» и «Загрузить из файла».

## Как урок считается пройденным

Плеер каждые 1,5 секунды смотрит внутрь урока: как только урок показывает
финальный бейдж «🎉 Отличная работа!», плеер засчитывает прохождение,
начисляет XP (50 + звёзды из урока) и отмечает день в серии.
Кнопка «✓ Завершить урок» — ручной запасной вариант.
