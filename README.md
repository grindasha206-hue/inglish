# Инглиш — мой сайт для изучения английского

Сайт: https://grindasha206-hue.github.io/inglish/

Личный сайт для занятий английским: уровни A1–B2, модули, интерактивные уроки,
прогресс, XP, серия дней, живая озвучка Groq и загрузка уроков прямо на сайте.

## Из чего состоит

```
index.html    — кабинет: уровни → модули → уроки, настройки, «Добавить урок»
player.html   — плеер: открывает урок, сам замечает прохождение, подменяет озвучку
site.js       — конфиг репозитория, загрузка course.json, озвучка Groq
progress.js   — прогресс (localStorage браузера)
course.json   — структура курса: уровни → модули → уроки
lessons/      — сами HTML-уроки
```

## Как добавить урок

Прямо на сайте: **＋ Добавить урок** → выбрать HTML-файл → выбрать уровень и
модуль (или создать новый модуль) → «Загрузить урок на сайт». Через минуту-две
урок появится. Нужен токен GitHub, один раз вставляется в Настройках.

Либо по-старому: файл в `lessons/` + запись в `course.json`.

## Озвучка

По умолчанию — голос браузера (роботизированный). Чтобы включить живые голоса:
Настройки → вставить API-ключ Groq (console.groq.com/keys) → выбрать голос →
Проверить. Плеер подменяет озвучку у кнопок 🔊 внутри уроков, сами уроки не
редактируются. Модель: canopylabs/orpheus-v1-english (голоса Autumn, Diana,
Hannah, Austin, Daniel, Troy). Если Groq недоступен — тихо откатывается на
голос браузера.

## Ключи и безопасность

Ключ Groq и токен GitHub хранятся ТОЛЬКО в localStorage браузера — в код сайта
и в репозиторий они не попадают (репозиторий публичный!). На новом устройстве
их нужно вставить заново в Настройках.

## Прогресс

Хранится в браузере (localStorage, ключ `english.progress.v1`).
Перенос на другое устройство: Настройки → «Сохранить прогресс в файл» /
«Загрузить из файла».

## Как урок считается пройденным

Плеер каждые 1,5 секунды смотрит внутрь урока: как только появляется финальный
бейдж «🎉 Отличная работа!», прохождение засчитывается, начисляются XP
(50 + звёзды из урока) и отмечается день в серии. Кнопка «✓ Завершить урок» —
ручной запасной вариант.
