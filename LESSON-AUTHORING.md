# Финальный шаблон грамматического урока (утверждён Дарьей 10.10.2026)

Основа: 11 уроков с сайта. Эталон реализации: lessons/urok-present-simple-questions.html. Общая механика: lesson-kit.js и lesson-template.js; общий стиль перенесённых уроков: lesson-theme.css; сохранение и серверная озвучка подключаются плеером.

## Блоки
| Блок | Содержимое |
|---|---|
| **A · Presentation** | Ситуация-заход с вопросом, **картинка** (присылает Дарья), 2 карточки-контраста, таблица формы, 3-5 примеров, одна плашка «частая ошибка». Образец: Unit 5 |
| **B · Vocabulary** | 8-12 слов (слово + перевод + озвучка) и chunks «соседи слов». Без IPA и частей речи |
| **C · Practice** | 4 игры: впиши, мемо, квиз, пары слово-перевод. В заголовке без числа игр |
| **D · Reading** | Текст 6-8 строк со словами урока и озвучкой. True/False, «расскажи то же про Тома», вставь слово. Образец: Units 5-6 |
| **E · Sounds** | 4 подтемы под грамматику урока: правило в одну строку, 3 примера с озвучкой, «Прослушать всё» |
| **F · Listening** | Новый диалог без текста, выбор скорости (медленно / обычно), вопросы True/False, скрипт скрыт до проверки. Берём из Vocab Review |
| **G · Production** | Тема из жизни, 5-8 предложений, подсказки-фразы, счётчик слов, образец по кнопке |
| **H · Homework** | 5 заданий: письмо, правописание, слушание, наблюдение, повторение. Задания с текстом выполняются **прямо на сайте** (поля ввода + чекбокс «сделано»), ответы сохраняются в прогрессе и в облаке. Кнопка «Распечатать» остаётся. Строка «к следующему разу» |

## Правила
- Sounds (произношение) и Listening (понимание) остаются оба.
- Грамматика только из уже пройденных юнитов.
- Выбор голоса внутри урока не нужен: он в плеере.
- Баннер грамматики кирпичный.
- Картинки для блока A присылает Дарья; в шаблоне под них зарезервировано место и подпись.

## Технические правила эталона
- У каждого поля постоянный уникальный `id`. Для заданий, создаваемых из массива: `fillList-0`, `qaList-0` и т. п. После публикации не менять смысл существующих идентификаторов. Новому заданию — новый идентификатор; новые элементы лучше добавлять в конец массива. Перестановка готовых полей домашки безопасна.
- `window.lessonStateVersion = "unit07-v1"` задаёт версию структуры ответов. Для другого урока — свой идентификатор. При несовместимом изменении смысла заданий увеличить версию: плеер сохранит старые ответы как конфликт, а не подставит их в новые вопросы.
- Урок подключает `<script src="../lesson-kit.js"></script>`. Плеер сам вставляет этот модуль внутрь изолированного урока. Для открытия урока отдельно нужен этот файл рядом с папкой lessons. Сохранение в аккаунте и Groq доступны через плеер; отдельно используется голос браузера.
- `LessonKit` содержит нормализацию, поля с проверкой, True/False, браузерную озвучку и очередь реплик. Логика, общая для новых уроков, меняется здесь.
- Урок сообщает результат через `window.lessonResult()` и собственные флаги через `getLessonState()` / `restoreLessonState()`. Общий механизм плеера сохраняет поля по ID, ответы игр и аудирования. Новые типы заданий требуют поддержки в плеере и проверки восстановления.
- Зачёт: минимум 80% правильных ответов в каждом проверяемом задании, все пары, просмотр A/B/E и самостоятельное письмо. Ошибки разрешено исправлять. В перенесённых уроках зачёт проверяется по текущим ответам, после изменения ответа нужно снова нажать «Проверить». Лучший результат и уже заработанный зачёт в кабинете сохраняются. В заданиях из четырёх вопросов 80% означает четыре правильных ответа.
- Production: не менее 25 слов и шести вопросов для этого урока. Это проверка объёма, не автоматическая оценка английского. Сообщение — «текст принят», проверка по образцу. В перенесённых уроках: 25 слов и минимум 5 предложений; в вопросительных — 6 вопросов. В словарных повторениях дополнительно 15 слов к картинке.
- Домашка сохраняется, но не блокирует итоговый зачёт. При отдельном открытии HTML облачного сохранения нет.
- Скрипт Listening открывается после ответа на все вопросы. Ошибки можно исправить после просмотра скрипта: это учебная практика, не экзамен.
- Для серии аудио использовать `LessonKit.playSequence(...)`, для отдельной реплики отменять очередь. Нельзя копировать циклы, которые продолжаются после отмены звука.
- Изображение пока не предоставлено: оставлена честная заглушка. Чтобы добавить, загрузить JPEG/PNG/WebP в `lessons/img/` и вписать в `data-lesson-image` значение вроде `img/unit-07-situation.jpg`. Плеер преобразует его в разрешённый встроенный ресурс. Максимум 2 МБ; SVG и внешние адреса здесь не поддерживаются. Отдельно открываемому HTML для такой картинки также нужен обычный `src` с тем же относительным путём.
- Для обучения интонации нужны прослушанные и проверенные записи. Синтезированный голос не считается эталоном интонации. Проверенные записи пока не предоставлены; интерфейс предупреждает об этом.
- Перед публикацией проверить прохождение, исправление ошибок, перезагрузку, домашку, остановку аудио и телефон. Все десять предыдущих уроков перенесены на A–H. Старые ответы переносятся по сохранённой подписи версии и точному сопоставлению полей. Незнакомая версия не подставляется наугад: плеер сохраняет резервную копию.

## Словарь курса (решение Дарьи, 10.10.2026: делаем оба варианта)
1. **Справочник:** после каждого нового урока его слова добавляются строками в `course_vocabulary.xlsx` (лист «Словарь», колонки: слово, транскрипция, перевод, часть речи, CEFR, частотность, chunk, пример; имена собственные на отдельном листе) и в CSV для ReWord (формат `"слово";"транскрипция";"перевод"`, UTF-8, файл на юнит).
2. **Словарь на сайте:** все слова по юнитам + повторение. Источник для будущего словаря сайта и экспортов — `vocabData` уроков. Ручное ведение XLSX отдельно может привести к расхождениям; экспорт из одного источника ещё предстоит реализовать.
Для этого в шаблоне B · Vocabulary слова урока лежат в одном массиве `vocabData` (слово, перевод, при необходимости транскрипция только в данных, не в показе).
По исходной спецификации (сам XLSX в этой работе не проверялся): xlsx покрывает Units 1-6 (353 слова); слова трёх Vocab Review берутся из них.

Перенесены Units 1–6, три Vocabulary Review и итоговый тест. Имена файлов и идентификаторы в course.json сохранены. В словарных повторениях остались оба текста, все словарные темы, все раунды пар и описание картинки. В контрольной сохранены 24 задания с отдельным результатом; чтение, звуки, аудирование и письмо после неё — дополнительное повторение.

В перенесённых файлах содержание хранится в window.lessonConfig, а упражнения создаёт LessonTemplate.mount. Для нового урока можно брать один из этих файлов: менять содержание, а не копировать обработчики. Не меняйте legacySignature и legacyFields: это карта переноса уже сохранённых ответов. При последующем изменении набора полей требуется новая версия и отдельная карта миграции.

Словарь прежних уроков сохранён целиком, даже когда он больше 8–12 слов. Точные фонетические записи и новые иллюстрации не добавлялись; прежние встроенные рисунки сохранены. Внешние библиотеки для сборки и платные сервисы для публикации не нужны.
