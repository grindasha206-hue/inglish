one/ones

one = a …; this one, the one, the brown one, some new ones

A
Presentation

one/ones

A · one (= a …)

Would you like one?

= Would you like a chocolate?

one = a/an … (a chocolate / an apple etc.)

  • I need a pen. Do you have one? (one = a pen)
  • A: Is there a bank near here?
    B: Yes, there's one at the end of this street. (one = a bank)

B · one и ones

one (singular)

Which one? = Which hat?

one = hat/car/girl etc.

this one / that one

  • Which car is yours? This one or that one? (= this car or that car)

the one …

  • A: Which hotel did you stay at?
    B: The one opposite the station.
  • I found this key. Is it the one you lost?

the … one

  • I don't like the black coat, but I like the brown one.
  • Don't buy that camera. Buy the other one.

a/an … one

  • This cup is dirty. Can I have a clean one?
  • That biscuit was nice. I'm going to have another one.

ones (plural)

Which ones? = Which flowers?

ones = flowers/cars/girls etc.

these/those or these ones / those ones

  • Which flowers do you want? These or those? or
    These ones or those ones?

the ones …

  • A: Which books are yours?
    B: The ones on the table.
  • I found these keys. Are they the ones you lost?

the … ones

  • I don't like the red shoes, but I like the green ones.
  • Don't buy those apples. Buy the other ones.

some … ones

  • These cups are dirty. Can we have some clean ones?
  • My shoes are very old. I'm going to buy some new ones.

Reading

Shopping

Найдите все one и ones. Какое слово они заменяют?

Yesterday I went shopping for a new coat. My old one is very old. In the first shop there were a lot of coats.

I didn't like the black ones, but I liked the green one. 'Which one do you want?' asked the assistant. 'The green one, please. Can I try a bigger one?'

Then I needed some new shoes. 'Which ones do you like?' my friend asked. 'The brown ones in the window.' But they were expensive, so I bought some cheaper ones.

At the café my cup was dirty, so I asked for a clean one. The cakes were great — I had another one!

В магазине

Напишите диалог в магазине (6–8 реплик): Which one do you want? — The … one. Which ones? — The … ones. Can I try a bigger one?

  • Which one / ones do you like?
  • The red one / the black ones, please.
  • Can I try a bigger / smaller one?
  • I'll buy some new ones.
