Would you like …? I'd like …

Вежливые предложения, приглашения и просьбы

A
Presentation

Would you like …? I'd like …

A · Would you like …? = Do you want …?

Would you like …? — когда предлагаем что-то:

  • A: Would you like some tea?
    B: No, thank you.
  • A: Would you like a biscuit?
    B: Yes, please.
  • A: What would you like, juice or water?
    B: Water, please.

Would you like to …? — когда приглашаем:

  • Would you like to go to the park?
  • A: Would you like to have dinner with us on Friday?
    B: Yes, I'd love to. (= I would love to have dinner with you)
  • What would you like to do tomorrow?

B · I'd like … — вежливый способ сказать «I want». I'd like = I would like

  • I'm hungry. I'd like something to eat.
  • (в турагентстве) I'd like some information about trips to Spain, please.
  • I'm tired. I'd like to stay at home tonight.

C · Would you like …? и Do you like …?

Would you like …? / I'd like …

Would you like some tea? = Do you want some tea?

  • A: Would you like to go to the theatre tonight? (= do you want to go tonight?)
    B: Yes, I'd love to.
  • I'd like an apple, please. (= can I have an apple?)
  • What would you like to do next Saturday?

Do you like …? / I like …

Do you like tea? = Do you think tea is nice?

  • A: Do you like going to the theatre? (in general)
    B: Yes, I go to the theatre a lot.
  • I like apples. (in general)
  • What do you like to do at weekends?

At the restaurant

Найдите Would you like…?, I'd like… и Do you like / I like.

Waiter: Good evening! Would you like a table for two?

Anna: Yes, please. By the window, if possible. — Waiter: Of course. Would you like something to drink?

Max: I'd like an orange juice, please. Anna, would you like some wine? — Anna: No, thanks. I'd like some water. I don't really like wine.

Waiter: And what would you like to eat? — Anna: I'd like the fish, please. — Max: I'd like a steak. And would you like to share a dessert later? — Anna: I'd love to!

Listening

Приглашение на день рождения.

Вопросы по прослушанному

Hi, Sam! Would you like to come to my birthday party on Saturday? I'd love to! What time? At seven. Would you like to bring your sister too? Yes, she'd like that. Does she like dancing? She loves dancing! Great. There'll be music. Would you like me to send you the address?
