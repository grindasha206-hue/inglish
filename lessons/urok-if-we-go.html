If we go … · If you see … etc.

if + present; if и when

A
Presentation

If we go … · If you see … etc.

A · if в начале или в середине

DAVID
Shall we go by bus or taxi?
If we go by bus, it will be cheaper.
ANNA
We'll get there more quickly if we go by taxi.

If может стоять в начале предложения или в середине:

If в начале

If we go by bus,it will be cheaper.
If you don't hurry,you'll miss the train.
If you're hungry,have something to eat.
If the phone rings,can you answer it, please?

if в середине

It will be cheaperif we go by bus.
You'll miss the trainif you don't hurry.
I'm going to the concertif I can get a ticket.
Is it OKif I use your phone?

В разговоре часто используют только часть с if:

  • 'Are you going to the concert?' 'Yes, if I can get a ticket.'

B · If you see Ann tomorrow … etc.

После if используем present (не will). Говорим 'if you see …' (не if you will see):

  • If you see Ann tomorrow, can you ask her to call me?
  • If I'm late this evening, don't wait for me. (не if I will be)
  • What shall we do if it rains? (не if it will rain)
  • If I don't feel well tomorrow, I'll stay at home.

C · if и when

If I go out = возможно, я выйду, но я не уверен:

ANNA
Are you going out later?
Maybe. If I go out, I'll close the windows.
TOM

When I go out = я выхожу (точно):

ANNA
Are you going out later?
Yes, I am. When I go out, I'll close the windows.
TOM

Сравните when и if:

  • When I get home this evening, I'm going to have a shower.
  • If I'm late this evening, don't wait for me. (не When I'm late)
  • We're going to play tennis if it doesn't rain. (не when it doesn't rain)

Reading

Tina's exam

Найдите предложения с if и when.

Tina has an exam next week. If she passes it, she'll get a certificate. If she fails, she can do it again in June.

Her friends want to have a picnic on Saturday. 'We can go to the beach tomorrow if the weather is good,' says Mark.

'I'll come if I have time,' says Tina. 'But if I don't finish my homework, I'll stay at home.'

'When you finish the exam, we'll have a big party!' says Mark. 'And if it rains, we'll have it at my flat.'
