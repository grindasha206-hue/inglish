some and any

some и any; something / anything

A
Presentation

some and any

A · some и any

some

I have some money.

some — в утвердительных предложениях:

  • I'm going to buy some clothes.
  • There's some milk in the fridge.
  • We made some mistakes.

any

I don't have any money.

any — в отрицательных предложениях:

  • I'm not going to buy any clothes.
  • There isn't any milk in the fridge.
  • We didn't make any mistakes.

B · any и some в вопросах

Do you have any money?

В большинстве вопросов (но не во всех) — any (не some):

  • Is there any milk in the fridge?
  • Does he have any friends?
  • Do you need any help?

some (не any) — когда мы что-то предлагаем (Would you like …?):

Would you like some coffee?
  • A: Would you like some coffee?
    B: Yes, please.

или просим (Can I have …? etc.):

  • A: Can I have some soup, please?
    B: Yes. Help yourself.
  • A: Can you lend me some money?
    B: Sure. How much do you need?

C · some и any без существительного

  • I didn't take any pictures, but Jessica took some. (= some pictures)
  • You can have some coffee, but I don't want any. (= any coffee)
  • I've just made some coffee. Would you like some? (= some coffee)
  • 'Where's your luggage?' 'I don't have any.' (= any luggage)
  • 'Are there any biscuits?' 'Yes, there are some in the kitchen.' (= some biscuits)

D · something / somebody и anything / anybody

something / somebody (or someone)

  • She said something.
  • I saw somebody (or someone).
  • Would you like something to eat?
  • Somebody's at the door.

anything / anybody (or anyone)

  • She didn't say anything.
  • I didn't see anybody (or anyone).
  • Are you doing anything tonight?
  • Where's Sue? Has anybody seen her?

Dinner tonight

Найдите some и any. Где утверждение, где отрицание или вопрос?

My friends are coming for dinner tonight, but I don't have any food in the fridge! There isn't any milk and there aren't any eggs.

So I went to the shop. I bought some vegetables, some cheese and some bread. I didn't buy any meat because my friends are vegetarian.

When I got home, somebody was at the door. It was my neighbour. 'Would you like some cake?' she asked. 'I made some this morning.'

Now I'm cooking. Is there anything I forgot? Do I need any wine? No — my friends don't drink. I'm ready!
