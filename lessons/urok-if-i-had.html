If I had … · If we went … etc.

If + past … would — нереальное условие сейчас

A
Presentation

If I had … · If we went … etc.

A · If he had the money, he would buy a fast car.

Dan likes fast cars, but he doesn't have one. He doesn't have enough money.

If he had the money, he would buy a fast car.

Обычно had — прошедшее время, но здесь had не прошедшее. If he had the money = если бы у него были деньги сейчас (но их нет).

Можно сказать:

  • If he had the money, he would buy a car.
    or He would buy a car if he had the money.

I'd / she'd / they'd etc. = I would / she would / they would etc.:

  • I don't know the answer. If I knew the answer, I'd tell you.
  • It's raining, so we're not going out. We'd get wet if we went out.
  • Jane lives in a city. She likes cities. She wouldn't be happy if she lived in the country.
  • If you didn't have a job, what would you do? (but you have a job)
  • I'm sorry I can't help you. I'd help you if I could. (but I can't)
  • If we had a car, we could travel more. (but we don't have a car, so we can't travel much)

B · If (I) was/were …

Можно сказать: if I/he/she/it was or if I/he/she/it were

  • It's not a very nice place. I wouldn't go there if I were you. (or … if I was you)
  • It would be nice if the weather was better. (or … if the weather were better)
  • What would Tom do if he were here? (or … if he was here)

C · Compare

Сравните:

if I have / if it is etc.

  • I must go and see Helen.
    If I have time, I will go today.
    (= maybe I'll have time, so maybe I'll go)
  • I like that jacket.
    I'll buy it if it isn't too expensive.
    (= maybe it will not be too expensive)
  • I'll help you if I can. (= maybe I can)

if I had / if it was etc.

  • I must go and see Helen.
    If I had time, I would go today.
    (= I don't have time today, so I will not go)
  • I like this jacket, but it's very expensive.
    I'd buy it if it wasn't so expensive.
    (= it is expensive, so I'm not going to buy it)
  • I'd help you if I could, but I can't.

→ if we go / if I have / if I can etc. — Unit 99

If I had more money …

Найдите предложения с if … would.

I live in a small flat in the city. I like it, but sometimes I dream.

If I had more money, I would buy a bigger house with a garden. If the house was near the sea, I would swim every day.

If I didn't have a job, I would travel around the world. If I could speak a foreign language well, I'd live in Italy.

But I have a job, and I'm learning English. If I worked harder, perhaps I would speak it better!

Listening

Что бы ты сделал?

Вопросы по прослушанному

What would you do if you won a lot of money? I'd buy a house by the sea. Would you stop working? No, I wouldn't. I'd be bored if I had nothing to do. And what would you do if you were me? I'd take a holiday. You work too much!
